# Free web deployment

Frontend on Cloudflare Pages, API on Render (free), Postgres on Neon (free). Nothing secret lives in the repo.

## 1. Database (Neon)
1. Sign up at neon.tech and create a project (region close to the Render region, e.g. Frankfurt).
2. Copy the connection details: host, database, user, password.
3. In GitHub: Settings > Secrets and variables > Actions. Add secrets `NEON_JDBC_URL` (`jdbc:postgresql://<host>/<db>?sslmode=require`), `NEON_DB_USER`, `NEON_DB_PASSWORD`, and the variable `DEPLOY_ENABLED=true`.
4. Run the "Migrate database" workflow once (Actions tab > Run workflow). It also runs on every push to main that touches `database/`.

## 2. API (Render)
1. Sign up at render.com with GitHub, then New > Blueprint and pick this repo (it reads `render.yaml`).
2. Fill the prompted env vars:
   - `ConnectionStrings__DefaultConnection`: `Host=<host>;Database=<db>;Username=<user>;Password=<password>;SSL Mode=Require`
   - `AiCoach__ApiKey`: your OpenRouter key
   - `Cors__AllowedOrigins__0`: the Pages URL from step 3 (no trailing slash). Set it after step 3 if needed.
   `JwtSettings__Key` and `PasswordSettings__Pepper` are generated by Render.
3. Note the API URL, e.g. `https://gymrat-api.onrender.com`.

## 3. Frontend (Cloudflare Pages)
1. dash.cloudflare.com > Workers & Pages > Create > Pages > connect the GitHub repo.
2. Root directory `frontend`, build command `npm run build`, output `dist`.
3. Environment variable `VITE_API_BASE_URL` = the Render API URL (no trailing slash). Deploy.
4. The site is at `https://<project>.pages.dev`. Put that origin into `Cors__AllowedOrigins__0` on Render.

## Cold starts
Render's free service sleeps after ~15 minutes idle; the first request then takes 30-60 s. A keep-alive ping (e.g. UptimeRobot on `/health` every 10 minutes, free) avoids this but uses most of the free monthly hours (750 h covers one always-on service). Neon also pauses when idle but wakes in about a second.
